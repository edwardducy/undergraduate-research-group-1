###### Abstract

Multi-task learning aims to learn multiple related tasks simultaneously and has achieved great success in various fields. However, the disparity in loss and gradient scales among tasks often leads to performance compromises, and the balancing of tasks remains a significant challenge. In this paper, we propose Dual-Balancing Multi-Task Learning (DB-MTL) to achieve task balancing from both the loss and gradient perspectives. Specifically, DB-MTL achieves loss-scale balancing by performing logarithm transformation on each task loss, and rescales gradient magnitudes by normalizing all task gradients to comparable magnitudes using the maximum gradient norm. Extensive experiments on a number of benchmark datasets demonstrate that DB-MTL consistently performs better than the current state-of-the-art.

## 1 Introduction

Multi-task learning (MTL) \[[4](#bib.bib24 ""), [61](#bib.bib13 ""), [7](#bib.bib14 "")\] jointly learns multiple related tasks using a single model, improving parameter-efficiency and inference speed compared to learning a separate model for each task. By sharing the model, MTL can extract common knowledge to improve each task’s performance. It has demonstrated its superiority in various fields, such as computer vision \[[49](#bib.bib38 ""), [57](#bib.bib46 ""), [25](#bib.bib58 ""), [24](#bib.bib59 ""), [34](#bib.bib57 "")\], natural language processing \[[30](#bib.bib49 ""), [33](#bib.bib47 ""), [46](#bib.bib48 ""), [6](#bib.bib39 ""), [52](#bib.bib16 "")\], and recommendation systems \[[47](#bib.bib44 ""), [18](#bib.bib45 ""), [51](#bib.bib40 ""), [58](#bib.bib60 "")\].

To learn multiple tasks simultaneously, equal weighting (EW) \[[61](#bib.bib13 "")\] is a straightforward method that minimizes the sum of task losses with equal task weights. However, it usually suffers from the challenging task balancing problem \[[49](#bib.bib38 ""), [26](#bib.bib6 "")\], in which some tasks perform well while others do not \[[45](#bib.bib41 "")\]. To alleviate this problem, a number of methods have been recently proposed by dynamically tuning the task weights. They can be categorized as loss balancing \[[21](#bib.bib20 ""), [32](#bib.bib25 ""), [55](#bib.bib11 ""), [56](#bib.bib61 ""), [54](#bib.bib56 ""), [31](#bib.bib17 "")\] and gradient balancing \[[8](#bib.bib27 ""), [42](#bib.bib12 ""), [9](#bib.bib15 ""), [59](#bib.bib8 ""), [28](#bib.bib7 ""), [29](#bib.bib29 ""), [52](#bib.bib16 ""), [38](#bib.bib9 ""), [15](#bib.bib21 "")\]. Loss balancing methods balance the tasks based on the learning speed \[[32](#bib.bib25 "")\] or validation performance \[[55](#bib.bib11 ""), [54](#bib.bib56 ""), [31](#bib.bib17 "")\] at the loss level, while gradient balancing methods balance the gradients by mitigating gradient conflicts \[[59](#bib.bib8 "")\] or enforcing gradient norms to be close \[[8](#bib.bib27 "")\] at the gradient level. However, recently, multiple extensive empirical studies \[[26](#bib.bib6 ""), [23](#bib.bib18 ""), [53](#bib.bib19 "")\] demonstrate that the performance of these existing methods is still unsatisfactory, indicating that task balancing is still an open problem.

To mitigate the task balancing problem, in this paper, we consider simultaneously balancing both the loss scales (at the loss level) and gradient magnitudes (at the gradient level). Since the loss scales/gradient magnitudes among tasks can be different, those with large values can dominate the update direction of the model, causing unsatisfactory performance on some other tasks \[[45](#bib.bib41 ""), [29](#bib.bib29 "")\]. Therefore, we propose a simple yet effective Dual-Balancing Multi-Task Learning (DB-MTL) method that consists of both loss-scale and gradient-magnitude balancing. First, we perform a logarithm transformation on each task loss to make all task losses have a similar scale. This is non-parametric and can recover the loss transformation in IMTL-L \[[29](#bib.bib29 "")\]. We find that the logarithm transformation also benefits existing gradient balancing methods. Second, we normalize all task gradients to the same magnitude as the maximum gradient norm. This is training-free and guarantees all gradients’ magnitude are the same compared with GradNorm \[[8](#bib.bib27 "")\]. Empirically, we find that the magnitude of normalized gradients plays an important role in performance, and setting it as the maximum gradient norm among tasks performs the best. Extensive experiments are performed on a number of benchmark datasets. Results demonstrate that DB-MTL consistently outperforms the current state-of-the-art.

## 2 Related Works

In an MTL problem with TT tasks, we aim to learn a model from {𝒟t}t\=1T\\{\\mathcal{D}\_{t}\\}\_{t=1}^{T}, where 𝒟t\\mathcal{D}\_{t} is the training dataset of task tt. The MTL model parameters can be divided into two parts: (i) task-sharing parameter 𝜽{\\bm{\\theta}}, and (ii) task-specific parameters {𝝍t}t\=1T\\{{\\bm{\\psi}}\_{t}\\}\_{t=1}^{T}. For example, in computer vision tasks, 𝜽{\\bm{\\theta}} usually represents a feature encoder (e.g., ResNet \[[19](#bib.bib5 "")\]) to extract common features among tasks, while 𝝍t{\\bm{\\psi}}\_{t} corresponds to the task-specific output module (e.g., a fully-connected layer). For parameter efficiency, 𝜽{\\bm{\\theta}} contains most of the MTL model parameters, and is crucial to the performance.

Let ℓt​(𝒟t,𝜽,𝝍t)\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t}) be the loss on task tt’s data 𝒟t\\mathcal{D}\_{t} using parameter (𝜽,𝝍t)({\\bm{\\theta}},{\\bm{\\psi}}\_{t}). The training objective of MTL is ∑t\=1Tγt​ℓt​(𝒟t,𝜽,𝝍t)\\sum\_{t=1}^{T}\\gamma\_{t}\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t}), where γt\\gamma\_{t} is the weight for task tt. Equal weighting (EW) \[[61](#bib.bib13 "")\] is a simple MTL approach that sets γt\=1\\gamma\_{t}=1 for all tasks. However, EW usually suffers from the task balancing problem in which some tasks have unsatisfactory performance \[[45](#bib.bib41 "")\]. To improve its performance, many other MTL methods have been proposed to dynamically tune the task weights {γt}i\=1T\\{\\gamma\_{t}\\}\_{i=1}^{T} during training. They can be categorized as loss balancing, gradient balancing, or hybrid balancing.

### 2.1 Loss Balancing Methods

This approach weights the task losses with {γt}i\=1T\\{\\gamma\_{t}\\}\_{i=1}^{T} that are computed dynamically. {γt}i\=1T\\{\\gamma\_{t}\\}\_{i=1}^{T} affect the update of both the task-sharing parameter 𝜽{\\bm{\\theta}} and task-specific parameter {𝝍t}t\=1T\\{{\\bm{\\psi}}\_{t}\\}\_{t=1}^{T}. They can be set based on measures such as homoscedastic uncertainty \[[21](#bib.bib20 "")\], learning speed \[[32](#bib.bib25 "")\], validation performance \[[55](#bib.bib11 ""), [54](#bib.bib56 "")\], and improvable gap \[[12](#bib.bib55 "")\]. Alternatively, IMTL-L \[[29](#bib.bib29 "")\] encourages the weighted losses {γt​ℓt​(𝒟t,𝜽,𝝍t)}t\=1T\\{\\gamma\_{t}\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t})\\}\_{t=1}^{T} to have similar loss scale across all tasks by transforming each loss ℓt​(𝒟t,𝜽,𝝍t)\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t}) as est​ℓt​(𝒟t,𝜽,𝝍t)−ste^{s\_{t}}\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t})-s\_{t}, where {st}t\=1T\\{s\_{t}\\}\_{t=1}^{T} are learnable parameters and obtained by gradient descent at each iteration.

### 2.2 Gradient Balancing Methods

The update of the task-sharing parameter 𝜽{\\bm{\\theta}} depends on all task gradients {∇𝜽ℓt​(𝒟t,𝜽,𝝍t)}t\=1T\\{\\nabla\_{{\\bm{\\theta}}}\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t})\\}\_{t=1}^{T}. Thus, gradient balancing methods aim to aggregate all task gradients in different manners. For example, MGDA \[[42](#bib.bib12 "")\] formulates MTL as a multi-objective optimization problem and selects the aggregated gradient with the minimum norm \[[14](#bib.bib36 "")\]. CAGrad \[[28](#bib.bib7 "")\] improves MGDA by constraining the aggregated gradient to be around the average gradient. MoCo \[[15](#bib.bib21 "")\] mitigates the bias in MGDA by introducing a momentum-like gradient estimate and a regularization term. GradNorm \[[8](#bib.bib27 "")\] learns task weights to scale the task gradients to similar magnitudes. PCGrad \[[59](#bib.bib8 "")\] projects the gradient of one task onto the normal plane of the other if their gradients conflict. GradVac \[[52](#bib.bib16 "")\] aligns the gradients regardless of whether the gradients conflict or not. GradDrop \[[9](#bib.bib15 "")\] randomly masks out gradient values with inconsistent signs. IMTL-G \[[29](#bib.bib29 "")\] learns task weights to enforce the aggregated gradient to have equal projections on each task gradient. Nash-MTL \[[38](#bib.bib9 "")\] formulates gradient aggregation as a Nash bargaining game.

For most gradient balancing methods (such as PCGrad \[[59](#bib.bib8 "")\], CAGrad \[[28](#bib.bib7 "")\], MoCo \[[15](#bib.bib21 "")\], GradDrop \[[9](#bib.bib15 "")\], and IMTL-G \[[29](#bib.bib29 "")\]), the task weight γt\\gamma\_{t} only affects update of the task-sharing parameter 𝜽{\\bm{\\theta}}, while in some other gradient balancing methods (such as MGDA \[[42](#bib.bib12 "")\], GradNorm \[[8](#bib.bib27 "")\], and Nash-MTL \[[38](#bib.bib9 "")\]), the task weight γt\\gamma\_{t} affects the update of both the task-sharing and task-specific parameters.

### 2.3 Hybrid Balancing Methods

As loss balancing and gradient balancing are complementary, these two types of methods can be combined to achieve better performance. In this approach, the task weight γt\\gamma\_{t} is obtained as the product of the loss and gradient balancing weights. For example, the first hybrid balancing method IMTL \[[29](#bib.bib29 "")\] combines IMTL-L with IMTL-G. Subsequently, various combinations \[[26](#bib.bib6 ""), [12](#bib.bib55 ""), [31](#bib.bib17 "")\] of loss/gradient balancing methods demonstrate performance improvements. In this paper, we propose DB-MTL that combines the logarithm transformation (for loss balancing) and the maximum-norm gradient normalization (for gradient balancing).

## 3 Proposed Method

In this section, we alleviate the task balancing problem from both the loss and gradient perspectives. First, we balance all loss scales by performing logarithm transformation on each task’s loss (Section [3.1](#S3.SS1 "3.1 Scale-Balancing Loss Transformation ‣ 3 Proposed Method ‣ Dual-Balancing for Multi-Task Learning")). Next, we achieve gradient-magnitude balancing by normalizing each task’s gradient to the same magnitude as the maximum gradient norm (Section [3.2](#S3.SS2 "3.2 Magnitude-Balancing Gradient Normalization ‣ 3 Proposed Method ‣ Dual-Balancing for Multi-Task Learning")). The procedure, called DB-MTL (Dual-Balancing Multi-Task Learning), is shown in Algorithm [1](#alg1 "Algorithm 1 ‣ 3.1 Scale-Balancing Loss Transformation ‣ 3 Proposed Method ‣ Dual-Balancing for Multi-Task Learning").

### 3.1 Scale-Balancing Loss Transformation

Tasks with different types of loss functions usually have different scales, leading to the task balancing problem. For example, in the NYUv2 dataset \[[44](#bib.bib22 "")\], the cross-entropy loss, L1L\_{1} loss, and cosine loss are used as the loss functions of the semantic segmentation, depth estimation, and surface normal prediction tasks, respectively. As observed in \[[45](#bib.bib41 ""), [59](#bib.bib8 ""), [38](#bib.bib9 "")\] and also in our experimental results in Tables [1](#S4.T1 "Table 1 ‣ Implementation Details ‣ 4.1 Evaluation on Scene Understanding ‣ 4 Experiments ‣ Dual-Balancing for Multi-Task Learning") and [6](#S4.T6 "Table 6 ‣ Effectiveness of Logarithm Transformation ‣ 4.4 Effectiveness of Loss and Gradient Balancing Components ‣ 4 Experiments ‣ Dual-Balancing for Multi-Task Learning"), surface normal prediction is affected by the other two tasks (semantic segmentation and depth estimation), causing MTL methods like EW to perform unsatisfactorily.

When prior knowledge of the loss scales is available, we can choose {st⋆}t\=1T\\{s\_{t}^{\\star}\\}\_{t=1}^{T} such that {st⋆​ℓt​(𝒟t,𝜽,𝝍t)}t\=1T\\{s\_{t}^{\\star}\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t})\\}\_{t=1}^{T} have the same scale, and then minimize the total loss ∑t\=1Tst⋆​ℓt​(𝒟t,𝜽,𝝍t)\\sum\_{t=1}^{T}s\_{t}^{\\star}\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t}). Previous methods \[[21](#bib.bib20 ""), [32](#bib.bib25 ""), [29](#bib.bib29 ""), [55](#bib.bib11 "")\] implicitly learn {st⋆}t\=1T\\{s\_{t}^{\\star}\\}\_{t=1}^{T} when learning the task weights {γt}t\=1T\\{\\gamma\_{t}\\}\_{t=1}^{T}. However, obviously the optimal {st⋆}t\=1T\\{s\_{t}^{\\star}\\}\_{t=1}^{T} cannot be obtained during training.

Without the availability of {st⋆}t\=1T\\{s\_{t}^{\\star}\\}\_{t=1}^{T}, the logarithm transformation can be used to alleviate the loss scale problem. Specifically, we transform each task’s loss ℓt​(𝒟t,𝜽,𝝍t)\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t}) to log⁡ℓt​(𝒟t,𝜽,𝝍t)\\log\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t}), and then minimize ∑t\=1Tlog⁡ℓt​(𝒟t,𝜽,𝝍t)\\sum\_{t=1}^{T}\\log\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t}). ### 3.2 Magnitude-Balancing Gradient Normalization

In addition to the task losses, task gradients also suffer from the scale issue. As the update direction of 𝜽{\\bm{\\theta}} is obtained by uniformly averaging all task gradients, it may be dominated by the large task gradients, causing sub-optimal performance \[[59](#bib.bib8 ""), [28](#bib.bib7 "")\].

A simple approach is to normalize task gradients to the same magnitude. As computing the batch gradient is computationally expensive, mini-batch stochastic gradient descent is often used in practice. The choice of αk\\alpha\_{k} is critical in alleviating the task balancing problem. Hence, the update for task-specific parameters is simply 𝝍t,k+1\=𝝍t,k−η​∇𝝍t,k​log⁡ℓt​(ℬt,k,𝜽k,𝝍t,k){\\bm{\\psi}}\_{t,k+1}={\\bm{\\psi}}\_{t,k}-\\eta\\nabla\_{{\\bm{\\psi}}\_{t,k}}\\log\\ell\_{t}({\\mathcal{B}}\_{t,k};{\\bm{\\theta}}\_{k},{\\bm{\\psi}}\_{t,k}) (steps [12](#alg1.l12 "In Algorithm 1 ‣ 3.1 Scale-Balancing Loss Transformation ‣ 3 Proposed Method ‣ Dual-Balancing for Multi-Task Learning")-[14](#alg1.l14 "In Algorithm 1 ‣ 3.1 Scale-Balancing Loss Transformation ‣ 3 Proposed Method ‣ Dual-Balancing for Multi-Task Learning")).

GradNorm \[[8](#bib.bib27 "")\] also aims to learn {γt}t\=1T\\{\\gamma\_{t}\\}\_{t=1}^{T} so that the scaled gradients have similar norms. However, it has two problems. First, alternating the updates of model parameters and task weights cannot guarantee all task gradients have the same magnitude in each iteration. Second, as will be seen from Figure [6](#S4.F6 "Figure 6 ‣ Effect of EMA’s Forgetting Rate 𝛽 in Eq. () ‣ 4.5 Sensitivity Analysis ‣ 4 Experiments ‣ Dual-Balancing for Multi-Task Learning") in Section [4.5](#S4.SS5 "4.5 Sensitivity Analysis ‣ 4 Experiments ‣ Dual-Balancing for Multi-Task Learning"), the choice of the update magnitude αk\\alpha\_{k} can significantly affect performance. However, this is not considered in GradNorm.

## 4 Experiments

In this section, we empirically evaluate the proposed DB-MTL on a number of tasks, including scene understanding (Section [4.1](#S4.SS1 "4.1 Evaluation on Scene Understanding ‣ 4 Experiments ‣ Dual-Balancing for Multi-Task Learning")), molecular property prediction (Section [4.2](#S4.SS2 "4.2 Evaluation on Molecular Property Prediction ‣ 4 Experiments ‣ Dual-Balancing for Multi-Task Learning")), and image classification (Section [4.3](#S4.SS3 "4.3 Evaluation on Image Classification ‣ 4 Experiments ‣ Dual-Balancing for Multi-Task Learning")).

### 4.1 Evaluation on Scene Understanding

#### Datasets

Following RLW \[[26](#bib.bib6 "")\], CAGrad \[[28](#bib.bib7 "")\], and Nash-MTL \[[38](#bib.bib9 "")\], the following two scene understanding datasets are used: 1. NYUv2\[[44](#bib.bib22 "")\], which is an indoor scene understanding dataset. It has 33 tasks (1313-class semantic segmentation, depth estimation, and surface normal prediction) with 795795 training and 654654 testing images. 2. Cityscapes\[[11](#bib.bib37 "")\], which is an urban scene understanding dataset. It has 22 tasks (77-class semantic segmentation and depth estimation) with 2,9752,975 training and 500500 testing images. 

#### Baselines

The proposed DB-MTL is compared with a number of MTL baselines, including 1. equal weighting (EW) \[[61](#bib.bib13 "")\]; 2. GLS \[[10](#bib.bib26 "")\], which minimizes the geometric mean loss ∏t\=1Tℓt​(𝒟t,𝜽,𝝍t)T\\sqrt\[T\]{\\prod\_{t=1}^{T}\\ell\_{t}(\\mathcal{D}\_{t};{\\bm{\\theta}},{\\bm{\\psi}}\_{t})}; 3. RLW \[[26](#bib.bib6 "")\], in which the task weights are sampled from the standard normal distribution; 4. loss balancingmethods including UW \[[21](#bib.bib20 "")\], DWA \[[32](#bib.bib25 "")\], IMTL-L \[[29](#bib.bib29 "")\], and IGBv2 \[[12](#bib.bib55 "")\]; 5. gradient balancingmethods including MGDA \[[42](#bib.bib12 "")\], GradNorm \[[8](#bib.bib27 "")\], PCGrad \[[59](#bib.bib8 "")\], GradDrop \[[9](#bib.bib15 "")\], GradVac \[[52](#bib.bib16 "")\], IMTL-G \[[29](#bib.bib29 "")\], CAGrad \[[28](#bib.bib7 "")\], MTAdam \[[35](#bib.bib53 "")\], Nash-MTL \[[38](#bib.bib9 "")\], MetaBalance \[[20](#bib.bib52 "")\], MoCo \[[15](#bib.bib21 "")\], and Aligned-MTL \[[43](#bib.bib50 "")\]; and 6. hybrid balancingmethod IMTL \[[29](#bib.bib29 "")\]. For comparison, we also include the single-task learning (STL) baseline, which learns each task separately.

All methods are implemented based on the open-source LibMTL library \[[27](#bib.bib10 "")\]. For all MTL methods, the hard-parameter sharing (HPS) pattern \[[3](#bib.bib30 "")\] is used, which consists of a task-sharing feature encoder and TT task-specific heads. For the proposed DB-MTL, following MoCo \[[15](#bib.bib21 "")\], we perform grid search for β\\beta over {0.1,0.5,0.9,0.1k0.5,0.5k0.5,0.9k0.5}\\{0.1,0.5,0.9,\\frac{0.1}{k^{0.5}},\\frac{0.5}{k^{0.5}},\\frac{0.9}{k^{0.5}}\\} for each dataset, where kk is the number of iterations.

## 5 Conclusion

In this paper, we alleviate the task-balancing problem in MTL by presenting Dual-Balancing Multi-Task Learning (DB-MTL), a novel approach that performs both loss-scale balancing (which makes all task losses have a similar scale via the logarithm transformation) and gradient-magnitude balancing (which rescales task gradients to comparable magnitudes using the maximum gradient norm). Extensive experiments on a number of benchmark datasets demonstrate that DB-MTL outperforms the current state-of-the-art. Moreover, the logarithm transformation can also benefit existing gradient balancing methods. For future work, we will extend our approach to incorporate gradient variance in addition to magnitudes for more refined task weighting, and develop theoretical analysis to provide convergence guarantees and optimality conditions for our method.
