# Git Commit Conventions

The repository follows Conventional Commits with one format for all commits:

- docs: for content changes, such as proposal chapters, research notes, and literature reviews.
- ci: for continuous integration and automated workflows, such as GitHub Actions and synchronization pipelines.
- chore: for tooling and configuration, such as pnpm, uv, vale, and dotfiles.
- fix: for corrections to content, workflows, or tooling.
- The summary is a lowercase imperative sentence.

Examples:

- docs: update chapter 1 draft outline with algorithmic balancing framing
- ci: add checksum flag to google drive sync workflow
- chore: configure vale research profile and update vocabulary
- fix: correct the TREC-IS citation year in the script
