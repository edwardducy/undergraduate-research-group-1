# Markdown Guidelines

- Keep every file readable in raw Markdown, without rendering.
- Write for non-native English speakers. Content must be clear on first reading and accurate in translation.
- Use plain, literal language that means exactly what it says in every culture.
- Use standard, widely understood verbs. Avoid obscure terms.
- Include explicit conjunctions and relative pronouns.

# Automated Enforcement

- Vale enforces the installed style rules automatically.
- Check your files with vale *.md.
- The rule files are in .vale/styles/ and the file .vale.ini enables them.
