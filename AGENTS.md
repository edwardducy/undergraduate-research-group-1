# Project Instructions

## Manuscript Writing Rules

These rules apply only to the manuscript files (`*.qmd`).

- **Style guide**: Follow the APA Publication Manual (7th edition), except where the rules below or the department's format differ.
- **Perspective**: Do not use first-person pronouns (I, we, our, us) or second-person pronouns (you, your).
- **Punctuation**: Do not use semicolons (;), colons (:), or em dashes (—) in the body text. The Definitions of Terms may use a colon after each term.

## Revision Workflow

The manuscript is under revision, so it cannot be trusted yet.

- **Transcript**: `transcript.md` records what the panel said.
- **Actions taken**: `panel-feedback.md` proposes the action taken for each comment, based on the transcript.
- **Changes**: `manuscript-changes.md` proposes changes to each section, based on the actions taken.
- **Revisions**: A proposal in either file may not hold up in the manuscript, so both files may still be revised.
