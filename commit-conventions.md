# Git Commit Conventions

The repository follows Conventional Commits with one format for all commits:

- docs: for content changes, such as the script, the glossary, the notes, and the literature corpus.
- chore: for tooling and configuration, such as pnpm, uv, vale, and the dotfiles.
- fix: for corrections to content or tooling.
- The summary is a lowercase imperative sentence.

Examples:

- docs: condense advisor feedback to settled facts
- docs: rename the proposal reference copy to original-proposal.md
- docs: polish the script narrative, add the public release, and expand the glossary
- chore: remove sample data and the encoder probe script
- fix: correct the TREC-IS citation year in the script
